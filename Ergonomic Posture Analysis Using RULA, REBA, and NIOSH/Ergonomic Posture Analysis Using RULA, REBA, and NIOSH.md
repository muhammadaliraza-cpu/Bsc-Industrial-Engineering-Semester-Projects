# Ergonomic Posture Analysis Using RULA, REBA, and NIOSH

A human factors engineering study of working posture and manual handling during wall construction.

## Project Overview

This semester project examined the posture of a wall-building worker using:

- Rapid Upper Limb Assessment (RULA)
- Rapid Entire Body Assessment (REBA)
- Revised NIOSH Lifting Equation framework

The study examined awkward body positions, repeated movements, load handling, and working conditions. It developed recommendations for improving task layout and reducing exposure to ergonomic risk factors.

## Project Objectives

- Assess upper-limb and whole-body posture.
- Examine manual lifting conditions.
- Identify awkward bending, twisting, reaching, and unsupported working positions.
- Propose improvements to working height, material placement, and footing.

## Assessment Methods

| Method | Application |
|---|---|
| RULA | Assess body posture with emphasis on upper-limb loading |
| REBA | Assess whole-body posture, load, coupling, and activity |
| NIOSH Lifting Equation | Examine lifting conditions and manual handling variables |

## Work Completed

1. Examined the selected wall-building posture and manual handling task.
2. Scored body segments using RULA and REBA worksheets.
3. Combined posture, load, muscle-use, coupling, and activity factors as applicable.
4. Reviewed lifting-task variables using the NIOSH framework.
5. Developed recommendations addressing the observed working conditions.

## Reported Findings

| Assessment | Reported Score | Report Interpretation |
|---|---|---|
| RULA | 7 | High postural risk requiring investigation and changes |
| REBA | 10 | High postural risk requiring corrective action |

The assessment identified concerns involving trunk bending, twisting, arm position, material handling, and unsupported footing.

## Proposed Improvements

- Adjust working height to reduce excessive bending and reaching.
- Position bricks and materials within convenient reach.
- Provide a stable working surface and secure footing.
- Review posture and material handling arrangements as wall height changes.
