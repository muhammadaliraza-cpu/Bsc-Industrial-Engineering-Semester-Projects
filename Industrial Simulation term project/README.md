# Industrial Simulation – BDWE Bakery Production System

## Project Overview
This term project was completed as part of the **Industrial Simulation** course at the Department of Industrial Engineering, University of Engineering and Technology (UET), Taxila.

The project involved modeling and analyzing the production system of BDWE Bakery using **ARENA Simulation**. The objective was to evaluate production performance, analyze resource utilization, and identify opportunities to improve productivity and operational efficiency.

## Production System
The bakery operates a single production line for three bread varieties:

- Rye Bread
- Poppy Seed Rolls
- Rye-Wheat Bread

The modeled production system consists of ten processes:

1. Loading powder into the mixing machine
2. Mixing
3. Unloading powder
4. Forming
5. Fermentation
6. Loading bread into the baking machine
7. Baking
8. Unloading bread
9. Cooling
10. Packaging

## Methodology
The project used discrete-event simulation to represent the bakery's production operations.

Key activities included:
- Identifying production entities, processes, resources, and operating parameters.
- Analyzing input data and processing-time distributions.
- Developing the ARENA simulation model.
- Evaluating scenarios with simulation run times of 24 hours, 10 days, and 30 days.
- Conducting sensitivity analysis using resource utilization and production performance measures.

## Simulation Results

The report presents the following average resource utilization figures:

| Resource | Average Utilization |
|---|---:|
| Load/Unload Operator | 20.98% |
| Forming Machine | 50.08% |
| Packer | 44.98% |

The analysis indicated opportunities to improve production through adjustments to proofer machine capacity, forming staff allocation, and load/unload operator allocation.
